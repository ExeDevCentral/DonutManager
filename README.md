## 🍩 Progressive Architectural Iterations

- **Version 1 (Procedural Scripting):** Basic state variables, array tracking, and direct DOM manipulation.
- **Version 2 (Modular Functions):** Functional separation of calculations, inputs, and output views.
- **Version 3 (Object-Oriented Domain Models):** Prototype/Constructor patterns instantiating store objects with independent sales formulas.
- **Version 4 (Modern Tailwind Dashboard):** Clean component layout with real-time stock projections, hourly sales charts, and batch additions.
